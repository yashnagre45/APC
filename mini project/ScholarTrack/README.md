# ScholarTrack
**Student Performance & Attendance Management System**

ScholarTrack is a small Python desktop application for managing student records, calculating marks and grades, monitoring attendance, and generating a class report.

## Features
- Add, update, delete and search student records
- Calculate average marks and grades automatically
- Calculate attendance percentage and flag students below 75%
- Dashboard cards for student count, class average, topper and low attendance
- Store records persistently in a CSV file
- Validate marks, email, roll number and attendance inputs
- Generate a simple class report

## Requirements
- Python 3.10+
- pandas

Install dependency:
```bash
python -m pip install pandas
```

## Run
```bash
python main.py
```

Records are stored in `data/students.csv`.

## Python concepts used
Functions, dictionaries, lists, classes, exception handling, regular expressions, CSV/file handling, Pandas, loops, conditions, and Tkinter GUI.

# Sample data

The records in `students.csv` are fictional sample data for demonstrating ScholarTrack.
- Marks are out of 100 for Python, Mathematics, and Computer Networks.
- `attended` is the number of lectures attended.
- `conducted` is the total lectures conducted.
- Attendance below 75% is flagged by the application.
- Example email addresses use `example.com` and are not real contacts.
